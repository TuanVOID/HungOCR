# OCR workspace

Operate surface for reviewing Vietnamese scanned documents locally.
Use a restrained green accent for actions and selection, off-white workspace,
white document panes, Segoe UI for Vietnamese text and familiar desktop controls.
The sidebar owns file selection, profile information and processing history.
The main workspace pairs the source PDF and raw OCR Markdown. Preserve textual
status, visible logs, explicit downloads, keyboard focus, and responsive stacking
below 1050 px. OCR text is inserted with textContent, never rendered as trusted HTML.
No decorative imagery is needed: the uploaded document is the visual content.
